Interfaces
==========

CEA offers several interfaces to interact with the software, allowing users to
choose the most suitable method for their workflow. Currently supported
interfaces include:

* :doc:`Python <interfaces/python_api>` for Python-based workflows and scripts.
* :doc:`MATLAB <interfaces/matlab_api>` for MATLAB usage through MATLAB's Python bridge.
* :doc:`Fortran <interfaces/fortran_api>` for the native Fortran subroutine interface.
* :doc:`C <interfaces/c_api>` for the C-language binding of the Fortran API.
* :doc:`Legacy Interface <interfaces/legacy_interface>` for the legacy command-line text
  interface.
